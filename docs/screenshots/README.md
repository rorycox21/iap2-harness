# Capture real CarPlay screenshots

With the live receiver running:

1. Open the CarPlay app grid. On the Mac press **Shift-Command-4**, then **Space**,
   and click the CarPlay window to capture that window alone.
2. Save it here as `carplay-home.png`.
3. Show the CarPlay dashboard and repeat, saving `carplay-dashboard.png`.
4. Check that no precise location, home/work address, private messages or contact
   names are visible. Use a neutral screen if those details cannot be hidden.
5. Add the images to the root README only after reviewing the actual files.

`carplay-live.png` is the original user-supplied screenshot of the live Mac
receiver and its terminal session, captured on 30 October 2026. It is embedded
in the root README without retouching. No mockup or placeholder image is
presented as working-product evidence.
